# Upcell — acompanhamento da disciplina

O diretório **upcell** reúne a visão acadêmica da disciplina Desenvolvimento Mobile I (UESB, 2026.2), com atividades, prazos e estado de acompanhamento.

## Linha do tempo

### Semana 1 — Introdução ao mobile
- Arquitetura e plataformas
- Ferramentas de desenvolvimento
- Design de interfaces
- Tendências e Inovações
- Atividade 1 — Tendências e Inovações (10 pontos, peso 2)
- Atividade 2 — Questionário (10 pontos, peso 1; 24/08 a 07/09/2026)
- Atividade 3 — Palavras cruzadas (10 pontos, peso 3)

### Semana 2 — Dart, Flutter e GitHub
- Introdução ao ambiente de programação
- Studio Firebase e GitHub
- Material complementar: Dart, capítulo 1
- Atividade 4 — link do código no GitHub (não pontuada; vencimento 07/09/2026)

### Semana 3 — Controle e Codespaces
- Roteiro de Estruturas de Controle
- Videoaula do GitHub Codespaces
- Dart, capítulos II e III
- Atividade 5 — questionário (10 pontos, peso 5; vencimento 14/09/2026)
- Atividade 6 — link da atividade no GitHub (10 pontos, peso 5; vencimento 14/09/2026)

### Semana 4 — Estruturas de dados
- Estrutura de Dados em Dart
- Material complementar: Dart, capítulo 9
- Local de envio do link do GitHub (vencimento 21/09/2026)

## Sistema de acompanhamento

Cada item deve iniciar como **Em aberto**. Depois da conclusão real no Moodle ou no GitHub, pode ser marcado como **Concluída** e receber um comentário com a data, o link e a observação da entrega. A marcação não substitui o envio oficial no Moodle.

O aplicativo usa essa trilha para exibir progresso, checks, comentários e pendências sem inventar entregas.
