UESB · ADS · 2026.2 · Unidade I · Semana 3

## Meu trabalho

Eu sou Thiago Ferreira Prates Neves, estudante de Tecnologia em Análise e Desenvolvimento de Sistemas da UESB. Neste repositório apresento meu trabalho da disciplina Desenvolvimento Mobile I e organizo o código desenvolvido durante a atividade.

## Objetivo da atividade

Configurar o ambiente no GitHub Codespaces, estudar estruturas de controle em Dart, executar o aplicativo Flutter Web e disponibilizar o projeto com versionamento no GitHub.

## Tecnologias utilizadas

- Flutter: estrutura do aplicativo multiplataforma.
- Dart: linguagem utilizada no código e nos exemplos de estruturas de controle.
- Flutter Web: alvo usado para executar a aplicação no navegador.
- Git e GitHub: controle de versões e armazenamento do código.
- GitHub Codespaces: ambiente de desenvolvimento na nuvem.
- HTML, CSS e JavaScript: arquivos de suporte da execução web do Flutter.

## Organização do projeto

- FlutterApp/: aplicativo da disciplina dentro deste repositório.
- FlutterApp/lib/: código-fonte Dart e Flutter.
- FlutterApp/test/: testes do aplicativo.
- FlutterApp/web/: suporte à execução no navegador.
- FlutterApp/docs/: documentação complementar.

Os arquivos que já existiam foram preservados. Esta documentação descreve o meu projeto e não substitui as orientações oficiais do Moodle.
